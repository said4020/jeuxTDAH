# Abysse — entraînement de l'attention

Jeu web d'entraînement de l'attention pour ados (13-17 ans), avec trois univers : Océan, Espace et Nature.
Le joueur pilote un avatar tout en capturant seulement les bonnes cibles. La difficulté s'adapte en continu, et un espace parent permet de limiter le temps de jeu quotidien.

Ce n'est pas un dispositif médical. C'est un jeu d'entraînement.

## À savoir
- La progression est enregistrée dans le navigateur de chaque appareil. Rien n'est envoyé sur Internet.
- Un parent peut créer un code à 4 chiffres dans « Espace parent », en bas de l'onglet *Jouer*, pour régler le temps de jeu. Il faut le faire sur chaque appareil.
